# Sunday Table

A responsive React + Vite restaurant website concept built for a developer portfolio.

## Run locally

```powershell
npm.cmd install
npm.cmd run dev
```

## Production build

```powershell
npm.cmd run build
npm.cmd run preview
```

## Before using for a real business

- Replace the sample menu, prices, address, and hours.
- Replace `whatsappNumber` in `src/App.jsx` with the restaurant's WhatsApp number in international format, digits only.
- Update the Google Maps link with the real address.
- Confirm image usage rights and use images licensed for the intended purpose.
- The booking form opens a pre-filled WhatsApp message. It does not confirm availability or store reservations.
- The menu and business information are fictional demonstration content.
